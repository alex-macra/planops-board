# Option B — Portfolio lens

Projects become the primary navigation object. The left explorer shows task and readiness counts; its per-project menu opens Roadmap, Board, or Dependencies already scoped to that project. The six view tabs remain available above the canvas.

## Walkthrough

1. Select a project in the explorer to carry its scope through Now, Roadmap, Rollup, Board, Backlog, and Dependencies.
2. Open the project's **…** menu and choose **Open board** to land directly in the project board. The view and project are recorded in the URL.
3. Use the view actions in the title card to cross from Roadmap to Board or Tasks without losing scope.
4. On a board card, use its visible menu to inspect details or dependencies, find it in Backlog, or move its status.

On narrow screens the project explorer becomes a horizontally scrollable strip. Existing planning, edit, and Git workflows stay intact.
